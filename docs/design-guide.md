# Design Guide

## 섹션 구성과 순서
Hero → About → Skills → Projects → Contact

## 분위기 / 톤
미니멀, 그레이톤, 여백 넉넉

## 색상
- 배경: #f3f6f9
- 글자: #6b7a99
- 보조 글자: #28478d
- 섹션 전환용 라이트 배경: #f5f5f4
- 포인트 컬러: #2f7f86 (라이트 배경 대비 4.30:1,
  본문 크기 텍스트에는 사용하지 않고 아이콘,
  큰 텍스트, 강조 요소에만 사용)
- 다크 테마 값 (app/globals.css 기준, planner 권장안, 확정 전):
  - 배경: #0f1729
  - surface: 미정 (임시값 #0f1729, 다크 배경과 동일)
  - 글자: #c5cde0
  - 보조 글자: #9db4ec
  - 포인트: #5fb3ba (제안값, 확정 전)
- 본문 텍스트는 보조 글자색(#28478d) 사용
- 글자색(#6b7a99)은 큰 제목과 라벨에만 사용

## 폰트
- 한글: Pretendard
- 영문: Geist (현재 프로젝트 기본값 유지)
- Pretendard 적용 방식: next/font/local

## 모션 효과 4종
1. 스크롤 등장: 아래에서 위로 페이드인
   (모든 섹션 공통)
2. 커서 반전: mix-blend-mode difference
   (데스크톱 hover 환경에서만)
3. 섹션 테마 전환: 스크롤에 따라
   다크 ↔ 라이트 배경 반전 (CSS 변수 교체)
4. 프로젝트 카드 hover: 살짝 올라오며
   이미지 확대 (hover 가능한 환경에서만)
공통: prefers-reduced-motion이면 전부 비활성

## 프로젝트 카드
- 서울30, 말해부엉 우선
- 상세 내용은 나중에 따로 정리
  (데이터는 플레이스홀더 구조)
